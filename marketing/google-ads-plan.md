# VelyxLabs — Google Ads Launch Plan

Everything below is paste-ready for ads.google.com. All copy is truthful —
real projects only, no invented metrics. Landing page: **https://www.velyxlabs.in/start**

---

## 0. One-time setup (do these first)

1. **Create account** at ads.google.com (same Google account as GA4/GSC). Skip "Smart campaign" — choose **Expert mode** (tiny link at the bottom).
2. **Link GA4:** GA4 → Admin → Product links → Google Ads links → link your new account.
3. **Import the conversion:** Google Ads → Goals → Conversions → New → Import → GA4 → select **book_call_click** → set as **Primary**.
4. Billing: add payment method. Set an account-level budget alert.

## 4. Week-by-week

- **Week 1:** Launch. Check daily: Search terms report → add junk queries as negatives.
- **Week 2:** Pause keywords with spend but 0 clicks-to-call intent. Keep tightening negatives.
- **Week 3–4:** If ~20+ conversions → switch bidding to Maximize conversions. Raise budget only on what converts.
- **Always:** judge by **book_call_click conversions**, not clicks. ₹ per conversion is the only number that matters.

## 5. Rules

- Never edit copy to promise results we can't prove. No fake stats in ads — account suspensions are real.
- /start page is deliberately excluded from sitemap (paid traffic page).
- Don't enable Google's "auto-apply recommendations" — turn them OFF (Settings → Recommendations).
